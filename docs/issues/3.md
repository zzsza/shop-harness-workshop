# 내 주문 목록 상태 필터

고객센터입니다.
주문이 많은 고객이 "배송중인 주문만 보고 싶다"고 자주 묻습니다.
내 주문 목록을 상태별로 걸러 볼 수 있게 해 주세요(결제완료, 배송준비, 배송중, 배송완료, 주문취소).
고른 필터는 새로고침해도 남아 있으면 좋겠습니다.

API는 지금 목록에 쿼리 하나를 더하는 모양으로 정했습니다.

- `GET /api/orders?status=<상태>`: 내 주문 중 그 상태인 것만, 지금처럼 최신순
- `status`가 없으면 지금처럼 전부
- 없는 상태 값이면 400 `VALIDATION_FAILED`
