# partial-refund 인터뷰

요청: 여러 상품을 산 고객이 그중 일부만 환불받을 수 있게 해 주세요.
상태: **PRD-ready**

오전 주문 취소 작업(`docs/tasks/order-cancel/`)에서 비범위로 뺀 것을 이어 간다.
현재 코드에서 본 사실: 주문은 주문 당시의 상품 합계·배송비·결제 금액을 저장한다(`orders.subtotal`, `shipping_fee`, `total`).
배송비 규칙은 `apps/api/src/orders/domain/shipping-fee.ts`의 두 상수(`SHIPPING_FEE`, `FREE_SHIPPING_THRESHOLD`)가 전부다.
주문 취소는 주문 품목 수량 전부를 `InventoryService.restoreForOrder`로 되돌린다.

## 질문과 답

| 번호 | 질문 | 추천 답 | 답 |
| --- | --- | --- | --- |
| D-1 | 어느 상태에서 부분 환불할 수 있나요? | 취소와 같게 결제완료·배송준비 | 예 |
| D-2 | 무엇을 단위로 환불하나요? | 상품별 수량. 한 상품 3개 중 1개도 된다 | 예 |
| D-3 | 남은 상품 금액이 무료배송 기준 아래로 떨어지면요? | 처음 무료배송이던 주문이면 배송비를 환불 금액에서 한 번 뺀다. 기준과 같으면 무료 그대로 | 예 |
| D-4 | 처음부터 배송비를 낸 주문은요? | 배송비는 돌려주지 않고 상품 금액만 환불 | 예 |
| D-5 | 모든 상품을 환불하려 하면요? | 거절하고 주문 취소를 쓰라고 안내 | 예 |
| D-6 | 환불 금액이 0원 이하가 되면요? | 거절 | 예 |
| D-7 | 재고는요? | 환불 수량만큼 되돌리고 입출고 이력에 "취소 복구"로 남긴다 | 예 |
| D-8 | 부분 환불 뒤 주문 전체를 취소하면요? | 남은 수량만 재고로 되돌린다 | 예 |
| D-9 | 같은 요청이 두 번 가면요? | 요청 번호(idempotencyKey)가 같으면 처음 결과를 그대로 돌려준다 | 예 |
| D-10 | 실제 돈은요? | 교육용 가상 결제라 실제 환불은 없다. 금액만 기록하고 보인다 | 예 |

## 비범위

- 관리자가 대신 환불하기, 환불 사유 입력, 환불 취소(되돌리기)
- 배송중·배송완료 주문의 반품
- 환불 금액 미리 보기 API

## 미해결

없음. `prd` Skill로 이어 간다.
