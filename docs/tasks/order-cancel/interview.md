# order-cancel 인터뷰

상태: PRD-ready
요청: 주문 취소랑 부분 환불 되게 해줘

## 지금 동작

- 주문 상태는 결제완료 → 배송준비 → 배송중 → 배송완료뿐이고 취소는 없다(`apps/api/src/orders/domain/order-status.ts`의 `NEXT_STATUS`).
- 관리자 상태 변경(`POST /api/admin/orders/:orderId/status`)은 다음 단계로만 넘긴다.
- 재고는 주문할 때 `InventoryService.decreaseForOrder`가 줄이고, 되돌리는 메서드는 없다(`apps/api/src/inventory/application/inventory-service.ts`).
- 입출고 이력의 종류는 `inbound`·`outbound` 둘뿐이고 DB `CHECK` 제약이 막는다(`packages/db/migrations/0001_init.sql`).
- 결제는 가상 결제라 실제로 돈이 오가지 않는다. 쿠폰과 포인트는 이 레포에 없다.

## 결정

첫 묶음(1~5)은 "예"로 추천대로, 둘째 묶음(6~9)도 "예"로 추천대로 정했다.

| ID | 질문 | 정한 답 | 추천대로 | 이유 |

| D-7 | 실수로 누르는 것은요? | 확인 창을 거친다. 되돌릴 수 없다고 먼저 알린다 | 예 | 취소는 되돌리는 길이 없다 |
| D-8 | 취소한 주문은 어떻게 보이나요? | 상태 이름은 "주문취소". 관리자 목록·상세에도 뱃지로 보이고 다음 단계 버튼은 없다 | 예 | 끝난 주문을 다시 넘기지 못하게 |

## 비범위

- 부분 환불(품목·수량 일부만 취소하고 그만큼 돌려주기). 오후 이슈로 넘긴다.
- 관리자가 고객 대신 취소하기, 취소 사유 입력.
- 실제 환불, 쿠폰·포인트 되돌리기(이 레포에 없다).
- 배송이 시작된 주문의 반품·교환.
