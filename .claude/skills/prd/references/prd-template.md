## 완료 기준

| AC | 상황·입력 → 행동 → 관찰할 결과 | 확인 방법 |
| --- | --- | --- |
| AC-1 | 구체적인 상황에서 행동하면 관찰할 수 있는 결과 | 테스트: 어떤 종류(API 통합, 도메인, 컴포넌트) |
| AC-2 | | 화면 확인: 계정 → 화면 → 누를 것 → 보일 것 |

확인 방법은 `테스트` 또는 `화면 확인` 둘 중 하나다.
`테스트`인 AC는 구현 때 테스트 이름에 slug와 AC 번호가 들어간다(예: `order-cancel AC-2 남의 주문은 취소할 수 없다`).
`화면 확인`인 AC는 review가 브라우저로 직접 눌러 보고 화면을 찍는다.
